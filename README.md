# Z0 website

Marketing site for **Z0**, a macOS companion for official Technic + Tekkit 2.

- Next.js App Router on Vercel
- Light / dark via `next-themes`
- Direct download of `Z0.app` at `/downloads/Z0-0.1.0-macos-arm64.zip`

## Develop

```sh
pnpm install
pnpm dev
```

## Production

```sh
pnpm build
vercel --prod
```
