# Security

## Supported release

The newest notarized Z0 release listed on the website is supported. Versioned download URLs are immutable.

## Report a vulnerability

Do not put an undisclosed vulnerability, credential, private log, world, account token, email address, home-folder path, or server address in a public issue.

Use the contact method published on the Z0 website's `/security` page. It is a
public reporting address; never commit credentials or private account data.

Ordinary setup problems belong with the contact method on the website's `/support` page. Share only the smallest redacted diagnostic excerpt needed to reproduce the problem.
