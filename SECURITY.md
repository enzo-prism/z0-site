# Security

## Supported release

The newest notarized Z0 release listed on the website is supported. Versioned download URLs are immutable.

## Report a vulnerability

Do not put an undisclosed vulnerability, credential, private log, world, account token, email address, home-folder path, or server address in a public issue.

Use **Security → Report a vulnerability** in this GitHub repository. If that private form is unavailable, open a public issue titled `Security contact requested` with no technical details so a private channel can be arranged.

Ordinary setup problems belong in the Z0 support issue form. Share only the smallest redacted diagnostic excerpt needed to reproduce the problem.
